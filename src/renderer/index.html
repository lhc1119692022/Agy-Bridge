Agy Bridge 注入器 + 本地中转站

上游

第三方 generateContent 中转站和本地 CLIProxyAPI 并列，注入器只选其中一个。

注入器

勾选模型后，用右侧队列调整 Antigravity 里的显示顺序。

本地引擎

你只需提供项目文件夹。中转站 URL 和客户端 Key 会从该目录的 config.yaml 自动读取；管理端登录仍在 CLIProxyAPI 自己的页面里。

管理 CLIProxyAPI

启动服务、登录管理页、添加账号。这里用的是管理密钥，不是下面的客户端 Key。

作为中转站使用

URL 和客户端 Key 来自项目 config.yaml 的 port / api-keys，不会使用管理端密码。

设置

系统代理用于 Antigravity 刷新 Google OAuth。不填则自动读取 Windows「系统代理」。127.0.0.1 不会走代理。

日志

注入器、CLIProxyAPI 和启动过程都会写到这里。
